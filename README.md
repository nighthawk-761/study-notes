# Study Notes

컴퓨터 과학을 공부하며 정리한 내용을 개념 중심으로 구성한 통합 노트입니다. 강의 주차 순서보다 주제 사이의 연결과 복습 편의성을 우선합니다.

## 주제 목록

- [Computer Networks (컴퓨터 네트워크)](topics/computer-networks/README.md)
- [Operating Systems (운영체제)](topics/operating-systems/README.md)

## 저장소 구조

```text
study-notes/
├── topics/       # 과목·주제별 노트
├── assets/       # 직접 제작한 이미지와 첨부 파일
└── templates/    # 새 노트와 주제용 템플릿
```

## 작성 원칙

- `topics/<주제>/` 아래에 주제별 폴더를 만듭니다.
- 문서는 주차가 아니라 `context-switching.md`, `tcp.md`처럼 개념을 드러내는 이름으로 나눕니다.
- 구조와 동작 과정은 가능한 경우 Markdown 표, Mermaid, 텍스트 도식으로 직접 설명합니다.
- 제3자 교안 이미지와 과제 제출물은 공개 노트에 포함하지 않습니다.
- 표준이나 구현 세부사항은 RFC, 공식 문서 등 원문 참고 링크를 함께 둡니다.
- 개인을 식별할 수 있는 이름, 학번, 연락처는 기록하지 않습니다.

## 문서 읽기

각 주제의 `README.md`에서 권장 학습 순서와 세부 문서로 이동할 수 있습니다. 각 문서 상단에는 페이지 내부 목차와 관련 노트 링크가 있습니다.
